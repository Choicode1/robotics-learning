c/c++ 단점:
  - 메모리 오류
  - 포인터 지옥
  - 버그 발생 시 디버깅 어려움

Java/Python 단점:
  - 속도 느림
  - 가비지 컬렉션(GC)으로 인해 성능제어 어려움

Rust 특징:
  - 메모리 안전 (컴파일 단계에서 에러로 잡아줌)
  - Ownership 시스템(소유권 규칙 사용). 메모리를 자동으로 관리. GC없음
  - Zero-cost Abstraction. 추상화해도 성능 손해 없음.

Rust만 가능한것
같은 변수 이름으로 다시 선언 가능

let x = 10;
let x = x + 5;

println!("{}", x); // 15

---------------------------------------------
let s1 = String::from("hello");  -> heap메모리
let s2 = s1;
- 이 경우 s1은 사라진다. s2로 소유권 이전
- 스코프{}를 벗어나면 메모리 해제

let s1 = 10;  -> 정수는 stack메모리
let s2 = s1;
- 이 경우는 복사가 된다.

- heap메모리 복사는 clone
let s1 = String::from("hello");
let s2 = s1.clone();
